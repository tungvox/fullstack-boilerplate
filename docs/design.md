# Vercel-inspired UI reference (getdesign)

This repo includes a **Vercel-inspired design specification** for agents and humans, generated by the [getdesign](https://getdesign.md) CLI ([npm](https://www.npmjs.com/package/getdesign)).

## Regenerate or refresh

From the repository root:

```bash
npm run design:vercel
```

Equivalent:

```bash
npx getdesign@latest add vercel
```

That writes or updates the root [`DESIGN.md`](../DESIGN.md) file (tokens, typography, components, and atmosphere). Treat it as a living document: commit changes when you intentionally refresh the spec, and customize it as the product evolves.

## How to use it

- Before building or refactoring UI, read **`DESIGN.md`** and align Tailwind/CSS with its tokens and patterns where practical.
- Pair this with the **`web-design-guidelines`** and **`react-best-practices`** skills from `vercel-labs/agent-skills` (see [`.cursor/skills/README.md`](../.cursor/skills/README.md)).

getdesign is a third-party tool; verify CLI behavior after major upgrades.
